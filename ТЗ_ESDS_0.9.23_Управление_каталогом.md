# ТЗ ESDS 0.9.23 — управление элементами каталога

**Плагин:** English Study Design Studio  
**Базовая версия:** 0.9.22  
**Целевая версия:** 0.9.23  
**Платформа:** Obsidian Desktop и Android  
**Изменение:** управление элементами непосредственно в карточках единого каталога.

## 1. Проблема
В каталоге пользовательской библиотеки карточка предоставляла только «Просмотр и применение». Основные операции были спрятаны в других разделах интерфейса или отсутствовали в контексте карточки. Это мешало управлять коллекцией с телефона.

## 2. Требования

### 2.1. Действия на карточке
Для элементов пользовательской библиотеки доступны:
- **Просмотр и применение** — открывает предпросмотр без немедленного применения.
- **Переместить** — позволяет указать целевую категорию.
- **Удалить** — запрашивает подтверждение перед удалением.
- **Дополнительное меню** — дублирование и экспорт отдельного элемента в JSON.

### 2.2. Перемещение
- Перемещение меняет категорию элемента, не меняя его ID, дизайн-данные и настройки.
- Для фоновых элементов сохраняется категория/группа, используемая каталогом.
- Отмена ввода или пустое название категории не меняет библиотеку.
- Новая категория может быть создана вводом её имени.

### 2.3. Удаление
- Удаление требует подтверждения.
- Удаляется только выбранный элемент соответствующего типа.
- Удалённый элемент убирается из списка избранного.
- При удалении активной палитры/фона выбирается безопасный встроенный вариант.
- При ошибке сохранения данные восстанавливаются и каталог перерисовывается.

### 2.4. Дублирование и JSON
- Дубликат получает новый уникальный пользовательский ID и имя с пометкой «копия».
- Экспорт JSON использует существующий формат отдельного элемента ESDS.
- Импорт старых форматов и существующие операции ZIP-коллекций не должны ломаться.

## 3. Android-интерфейс
- Кнопки имеют сенсорную высоту не менее 36 px в стилях каталога.
- Действия переносятся на следующую строку при узкой ширине.
- Кнопки не должны обрезаться или требовать горизонтальной прокрутки карточки.
- Существующий предпросмотр остаётся доступен нажатием карточки.

## 4. Совместимость и безопасность
- Версия плагина: 0.9.23.
- Формат пользовательской библиотеки и LIBRARY_SCHEMA не повышаются.
- Не менять применение оформления к заметке, frontmatter и содержимое заметок.
- Не удалять и не заменять data.json при обновлении.
- Не включать data.json в установочный ZIP.
- Не менять основную ветку автоматически: изменения подготовлены в отдельной ветке и Draft PR.

## 5. Критерии приёмки
1. Перемещение палитры в другую категорию сохраняет её ID и параметры.
2. Перемещение фона отображается в правильной категории.
3. Отмена перемещения оставляет исходные данные без изменений.
4. Удаление требует подтверждения и обновляет счётчик каталога.
5. Удаление элемента из избранного очищает только соответствующую запись.
6. Удаление активного элемента не оставляет невалидную ссылку.
7. Дублирование создаёт отдельный элемент с уникальным ID.
8. Экспорт JSON можно повторно импортировать в библиотеку.
9. Поиск, фильтрация, предпросмотр и ZIP импорт/экспорт продолжают работать.
10. main.js проходит синтаксическую проверку; JSON версии корректен; ZIP проверен на целостность и не содержит data.json.
11. Отдельно проверено реальное поведение в Obsidian Android.
