# Cosmic Fantasy — 50 космических градиентных палитр ESDS 0.9.33

Коллекция содержит 50 самостоятельных дизайнерских наборов для ESDS 0.9.33. Каждый JSON — законченный пакет: палитра, индивидуальный фон и стиль учебных блоков.

## Цветные учебные блоки
Все 12 типов Callout имеют собственные оттенки заливки и рамок. Цвета согласованы с общей космической палитрой, но достаточно различаются, чтобы соседние блоки не сливались визуально.
- Заливка заметнее отделяется от градиентного фона.
- Для каждого типа Callout задан свой цвет заливки, текста заголовка и рамки.
- Плотность заливки настроена отдельно для Light и Dark и индивидуально для типов блоков.
- Цвет заголовка выбран тёмным для светлой тонированной поверхности.

## Состав каждого набора
- 11 семантических цветовых ролей, включая отдельные роли иностранной буквы, иностранного слова, IPA, перевода, термина и определения.
- 12 типов Callout с независимыми заливками, текстом и рамками.
- Собственный космический градиентный фон.
- Собственный стиль учебных блоков.

## Совместимость
- Формат: esds-palette, schemaVersion 5.
- Целевая версия: ESDS 0.9.33.
- Фоны используют поддерживаемые плагином CSS linear-gradient() и radial-gradient().
- Фон и стиль блоков импортируются вместе с палитрой и связываются по ID.

## Импорт
В ESDS 0.9.33 открой библиотеку и используй импорт ZIP-коллекции. Для сохранения связки палитры, фона и стиля блоков импортируй коллекцию целиком.

Контраст заливок проверен после смешивания с соответствующими остановками градиентного фона. Реальный рендеринг внутри Obsidian Android необходимо подтвердить после импорта.
