# ESDS 0.9.24

- Палитра использует один фиксированный набор цветов во всех темах Obsidian.
- Удалён Light/Dark переключатель из редактора пользовательских палитр.
- Предпросмотр, карточки, применение к заметкам и CSS-генератор используют единые роли и цвета Callout.
- Старые палитры нормализуются: сохраняется основной набор, альтернативные dark-поля удаляются.
- JSON и ZIP экспорт используют schemaVersion 4.
- Сохранены функции каталога 0.9.23, отдельная библиотека фонов и локальные настройки блоков.

Проверены статически ключевые преобразования исходника и схема экспорта. Obsidian на Android/Desktop в этой среде не запускался; требуется ручная проверка.
