# ESDS 50 — Элегантные и премиальные

**50 палитр · ESDS 0.9.33 · schemaVersion 5**

- №01–20: ранее утверждённые цветовые концепции.
- №21–50: 30 новых насыщенных драгоценных и премиальных фонов.
- Все фоны независимы от системного оформления Obsidian: обе внутренние схемы палитры содержат одинаковые значения.
- Каждый фон строится как полноценная концепция: градиент, световой эффект/блик, затем контрастные семантические роли и учебные карточки.
- Основной текст карточек: 16.2 px / Medium 500. Заголовки: 15.5 px / Semibold 650.
- 12 стандартных Callout, отдельные цветовые заливки, читаемый текст и заметные рамки.
- Таблицы и колонки остаются без цветных фоновых заливок.

## Импорт
Скачай ZIP ветки через GitHub **Code → Download ZIP**. В ESDS импортируй JSON-файлы из папки `palettes`.

## Демонстрация
`demo/Elegant-Premium-Showcase.md` показывает 30 семантических классов и стандартные учебные блоки.
