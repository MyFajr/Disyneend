# ESDS — Радужные и многоцветные

**25 палитр · ESDS 0.9.32 · palette schema v4 · 11 цветовых ролей · 12 типов Callout**

В наборе 25 самостоятельных многоцветных палитр. Каждая палитра содержит все 11 ролей ESDS 0.9.32, включая отдельный цвет иностранных букв `letter`, полные карты цветов/заливок/текста/границ для 12 поддерживаемых Callout и индивидуальную геометрию рамок.

## Файлы

- `Rainbow-Multicolor-25.esds-export.json` — единый JSON для массового импорта всех 25 палитр через **Библиотека ESDS → Импорт палитр**. Импортёр 0.9.32 распознаёт `type: "esds-export"` и обрабатывает список `items`.
- `Theme-Packs/` — 25 отдельных файлов `.esds-theme.json`. Каждый файл переносит палитру, яркий цветной фон и согласованный стиль учебных блоков. Импортировать через **Импорт дизайнерского набора**.

## Важные детали совместимости

- Все standalone-палитры имеют оболочку `schemaVersion: 4`, `type: "esds-palette"`, `palette: {...}`.
- Полные наборы используют `schemaVersion: 1`, `type: "esds-theme-pack"`, `plugin: "english-study-design-studio"` и объекты `items.palette`, `items.background`, `items.blockStyle`.
- Все 11 ролей заданы HEX-цветами: `en`, `letter`, `ipa`, `translation`, `term`, `definition`, `focus`, `secondary`, `soft`, `heading`, `ink`.
- Фон каждой палитры яркий, многоцветный и имеет контрастный тёмный текст. Внутренние слоты Obsidian appearance получают одинаковые значения: это не две пользовательские версии дизайна.
- Не добавляются неподдерживаемые настройки окраски отдельных столбцов Markdown-таблиц. Существующие 30 семантических классов и 32 декоративных стиля блоков не изменяются.

## Проверка

JSON-структуры сформированы по спецификации и импортёру ветки ESDS 0.9.32. Реальный импорт и визуальная проверка на устройстве Android не выполнялись; их нельзя считать пройденными автоматически.
