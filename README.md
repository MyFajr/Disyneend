# Cosmic Fantasy — 50 космических градиентных палитр ESDS 0.9.33

Коллекция содержит 50 самостоятельных дизайнерских наборов для ESDS 0.9.33. Каждый JSON — законченный пакет для импорта через «ZIP-коллекция»: палитра, индивидуальный фон и стиль учебных блоков связаны внутри одного файла.

## Состав каждого набора
- 11 семантических цветовых ролей, включая отдельные роли иностранной буквы, иностранного слова, IPA, перевода, термина и определения.
- 12 типов Callout с цветами заливки, текста, рамок и конфигурацией рамок.
- Собственный космический фон с плавными цветовыми переходами.
- Контрастные цвета текста, рассчитанные относительно всех цветовых остановок фона.
- Собственный стиль учебных блоков.

## Художественное направление
Галактики, туманности, сверхновые, квазары, полярные сияния, звёздная пыль, ледяные миры, жемчужные облака, призматические и радужные пространства. В коллекции 25 глубоких тёмных миров и 25 светлых пастельных миров.

## Совместимость
- Формат: esds-palette, schemaVersion 5.
- Целевая версия: ESDS 0.9.33.
- Фоны используют поддерживаемые плагином CSS linear-gradient() и radial-gradient(); значения Light и Dark совпадают, чтобы дизайн сохранялся при смене темы Obsidian.
- Все 30 семантических классов обслуживаются механизмом ESDS 0.9.33.
- Фон и стиль блоков импортируются вместе с палитрой и связываются по ID.

## Импорт
В ESDS 0.9.33 открой библиотеку и используй импорт ZIP-коллекции. Для сохранения связки палитры, фона и стиля блоков импортируй коллекцию целиком.

Фактическое отображение в Obsidian Android необходимо проверить после импорта: структура, допустимость CSS-значений и контраст проверяются здесь, но реальный Android-рендеринг в этой среде недоступен.
