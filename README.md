# ESDS — Elegant & Premium 30

Отдельная коллекция из 30 одобренных палитр ESDS 0.9.33.

## Как использовать
1. Скачай ZIP этой ветки через **Code → Download ZIP**.
2. Если хочешь использовать многослойные фоновые эффекты и вес текста Medium, скопируй `plugin-patch/main.js` и `plugin-patch/styles.css` в папку установленного ESDS 0.9.33 с заменой этих двух файлов. `manifest.json` оставь прежним.
3. Перезапусти Obsidian.
4. В ESDS импортируй ZIP-коллекцию.
5. Скопируй `ESDS-30-Elegant-Premium-0.9.33/demo/Elegant-Premium-Showcase.md` в свой vault. Открой заметку, выбери любую палитру и нажми «Применить».

В архиве находятся только 30 палитр, manifest коллекции, демонстрационный урок и два файла совместимого патча. Другие коллекции не включены.
