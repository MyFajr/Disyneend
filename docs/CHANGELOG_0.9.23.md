# ESDS 0.9.23

## Добавлено
- Отдельное окно управления пользовательской библиотекой для палитр, фонов и стилей блоков.
- Выбор отдельных элементов, выбор всех результатов поиска и снятие выбора.
- Массовое перемещение, дублирование, JSON-экспорт и удаление.
- Переименование и перемещение отдельных элементов.
- Создание категории при перемещении в новую категорию.
- Быстрый доступ к менеджеру категорий из каждой вкладки библиотеки.
- Панель действий на карточках библиотеки: предпросмотр, меню управления и избранное.

## Сохранность
- Изменения сохраняются через штатный data.json / saveUserLibrary.
- При ошибке сохранения выполняется откат пользовательских данных.
- Содержимое заметок, Properties/frontmatter и cssclasses не меняются.
