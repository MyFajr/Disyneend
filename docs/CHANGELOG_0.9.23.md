# ESDS 0.9.23 — журнал изменений

- UX предпросмотра: верхний крестик, Light/Dark в основном окне, компактные нижние действия, окно без вертикальной прокрутки.
- Каталог: удалена отдельная кнопка «Просмотр и применение»; карточка открывает предпросмотр целиком.
- Навигация: унифицировано вертикальное выравнивание кнопок «Назад».
- Без изменений: форматы палитр, сами палитры, CSS-классы заметок, логика снятия оформления, хранение библиотеки и миграция.
- Android: необходима проверка на реальном Obsidian Android/WebView.
