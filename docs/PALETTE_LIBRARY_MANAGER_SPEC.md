# Техническое задание — Palette Library Manager для ESDS

## Цель
Добавить полноценное управление библиотекой палитр по UX-паттернам файловых менеджеров, не меняя основную ветку ESDS 0.9.22.

## Интерфейс коллекции
- Категории работают как папки; поиск охватывает библиотеку.
- Режимы отображения: сетка и список.
- Сортировка по порядку добавления, названию и дате.
- Мобильная компоновка для Android, крупные зоны касания.

## Выделение
- Выбор чекбоксом.
- Выбрать всё в текущих результатах/категории.
- Снять выделение и инвертировать выделение.
- Shift + выбор диапазона при наличии клавиатуры.
- Счётчик выбранных элементов.

## Массовые действия
- Удаление выбранных пользовательских палитр с подтверждением; встроенные защищены.
- Перемещение выбранных палитр в существующую или новую категорию.
- Копирование с уникальными ID и именами.
- Массовое переименование с нумерацией и предотвращением конфликтов.
- Экспорт выбранных палитр в ZIP.

## Импорт и конфликты — требование к завершению
- Для ZIP и множественного JSON импорта не пропускать дубликаты молча.
- Распознавать совпадение по ID и имени без учёта регистра.
- Предлагать: Пропустить, Заменить, Переименовать вручную, Автоматически переименовать с номерами.
- Действие для каждого конфликта и «Применить ко всем оставшимся».
- Предпросмотр количества добавлений/замен/переименований/пропусков.
- Замена сохраняет ID существующей записи; импортированные данные Light/Dark и все роли сохраняются.
- Ошибочные JSON выводятся отдельным отчётом, остальные валидные файлы импортируются.

## Безопасность
- Обычный импорт палитр не заменяет библиотеку целиком.
- Подтверждать разрушительные действия.
- Защищать встроенные палитры от удаления/замены.
- Проверять уникальность ID и названий.
- Откатывать изменения при ошибке сохранения.

## Приёмка
Проверить длинные списки и Android WebView; выделение, диапазоны, инверсию, удаление, перенос, копирование, массовое переименование, ZIP экспорт; все варианты конфликтного импорта; откат при ошибке сохранения.
