# ESDS 0.9.24 — Category File Manager

- Добавлена вложенная структура категорий палитр через parentId.
- Выделение категорий прямо в каталоге: режим выбора, чекбоксы, выбор всех категорий текущего уровня, снятие выделения и счётчик.
- Массовое перемещение категорий в корень или внутрь другой категории через сенсорный список назначения; добавлена защита от циклов.
- Создание категории и подкатегории доступно прямо на текущем уровне каталога.
- Массовое рекурсивное удаление категорий вместе с дочерними категориями и палитрами.
- Встроенные палитры удалённых категорий скрываются через deletedBuiltinPaletteIds; пользовательские палитры удаляются.
- Пустой сохранённый список категорий не восстанавливает значения по умолчанию.
- Существующие действия над палитрами и ZIP-экспорт сохранены.

Проверки и ограничения указаны в отчёте после фактического выполнения. Реальное тестирование в Obsidian Android не заявляется без устройства.
