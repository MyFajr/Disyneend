# Техническое задание ESDS 0.9.23 — управление библиотекой

## 1. Цель
Добавить в English Study Design Studio полноценный интерфейс управления пользовательской библиотекой, ориентированный на привычные операции файлового менеджера. Управление доступно отдельно для палитр, фонов и дополнительных стилей блоков.

## 2. Область изменений
- Только интерфейс и операции с элементами пользовательской библиотеки ESDS.
- Категории выступают папками/группами внутри соответствующего типа элементов.
- Не создавать и не менять содержимое палитр, фоновых наборов и стилей как дизайнерских данных.
- Не менять алгоритм применения оформления к заметкам, CSS-классы заметок, Properties/frontmatter и формат содержимого заметок.

## 3. Функции управления элементами
### 3.1. Единичные действия
Для каждого пользовательского элемента:
- переименовать;
- переместить в существующую или новую категорию;
- дублировать;
- удалить с подтверждением;
- открыть предпросмотр;
- добавить/убрать из избранного;
- открыть существующие действия элемента (редактирование, экспорт и удаление там, где они уже реализованы).

### 3.2. Массовые действия
В окне управления:
- выбрать отдельные элементы;
- выбрать все элементы текущего списка/результата поиска;
- снять выделение;
- переместить выбранное в категорию (если категории нет — создать её);
- дублировать выбранное;
- экспортировать выбранное в отдельный JSON-файл библиотеки;
- удалить выбранное с подтверждением.

Выбор и массовые операции ограничены активным типом библиотеки: палитры, фоны или стили блоков. Это предотвращает случайное смешивание несовместимых структур.

## 4. Управление категориями
Использовать существующий менеджер категорий:
- создать категорию;
- переименовать категорию с переносом её элементов;
- удалить категорию с переносом элементов в категорию назначения;
- менять порядок категорий;
- защищённые системные категории не удалять и не переименовывать.

Добавить доступ к менеджеру категорий из каждой вкладки библиотеки.

## 5. Поиск и мобильный интерфейс
- Поиск в менеджере фильтрует список по названию и категории.
- «Выбрать всё» действует на текущий отфильтрованный список.
- Элементы имеют отдельные touch-кнопки; действия не должны случайно открывать предпросмотр карточки.
- Список прокручивается независимо от панели действий.
- Интерфейс адаптируется к узкому экрану Android.

## 6. Сохранность данных
- Изменения сохраняются через штатный механизм userData / saveUserLibrary.
- Не менять схему хранения и не создавать новые папки в .obsidian.
- При ошибке сохранения откатывать изменение массива и избранного к предыдущему состоянию.
- Удаление элемента также удаляет только соответствующие ссылки на него в ESDS-избранном.
- Встроенные элементы Obsidian/ESDS не должны становиться объектами удаления из пользовательской библиотеки.
- Не изменять заметки, YAML/frontmatter, cssclasses и файлы пользователя.

## 7. Критерии приёмки
1. Менеджер открывается для трёх типов пользовательской библиотеки.
2. Поиск, выбор всех видимых элементов и снятие выбора работают.
3. Перемещение обновляет категорию и корректно работает с новой категорией.
4. Переименование сохраняет имя и обновляет подпись фона, если это фон.
5. Дублирование создаёт новые уникальные ID и сохраняет исходник.
6. Удаление требует подтверждения и очищает связанные избранные ссылки.
7. Экспорт выбранных элементов создаёт JSON в папке ESDS Exports.
8. Доступ к менеджеру категорий есть во всех трёх вкладках.
9. Действия на карточках не перехватываются открытием предпросмотра.
10. Существующий механизм применения палитр/фонов/стилей не изменён.

## 8. Проверки и ограничения
- Проверка синтаксиса main.js выполняется перед публикацией.
- Проверка CSS и функциональное тестирование на Android/Obsidian выполняются отдельно на устройстве.
- Нельзя объявлять Android-тест пройденным без фактической проверки на устройстве.
