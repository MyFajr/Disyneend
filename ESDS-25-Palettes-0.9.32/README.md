# Rainbow Multicolor — 25 полных дизайнерских наборов ESDS 0.9.33

В коллекции 25 самостоятельных JSON-файлов формата `esds-palette`, schemaVersion 5.

**Каждый файл содержит сразу три связанные части:**
- палитру со всеми 11 семантическими цветовыми ролями, включая отдельный цвет иностранной буквы;
- собственный цветной градиентный фон заметки;
- собственный стиль информационных блоков и Callout.

Архив предназначен для прямого импорта через **«ZIP-коллекция» в ESDS 0.9.33**. Импортёр добавляет фон и стиль блоков в библиотеку, назначает новые уникальные ID и связывает их с палитрой. Поэтому палитра больше не должна подменяться стандартным фоном «Слоновая кость».

Фоны индивидуальны для каждой палитры; значения Light и Dark намеренно одинаковы, поэтому внешний вид заметки не меняется при переключении темы Obsidian. Цветовые роли проверены расчётом контрастности относительно обоих концов каждого градиента (минимум 4.5:1).

В каждой палитре заполнены 12 поддерживаемых типов Callout. Все 30 семантических CSS-классов обслуживаются механизмом ESDS 0.9.33.

**Важно:** для импорта этой коллекции сначала обнови ESDS до 0.9.33. В 0.9.32 импортёр не переносит связанные фон и стиль блоков из файла палитры, из-за чего и возникал одинаковый фон.

Ограничение ESDS 0.9.33: индивидуальные фоны отдельных столбцов Markdown-таблицы пока не поддерживаются. Проверка реального отображения на Android-устройстве всё ещё необходима.
