# Rainbow Multicolor — 25 палитр ESDS 0.9.32

25 отдельных JSON-палитр формата `esds-palette`, schemaVersion 4, и manifest коллекции. ZIP этой ветки содержит только эти палитры и README, поэтому его можно напрямую передать в «ZIP-коллекция» ESDS. Все 11 цветовых ролей, включая `letter`, и 12 Callout типов заполнены. 30 семантических классов обслуживаются ESDS 0.9.32. Индивидуальные фоны столбцов Markdown-таблиц не поддерживаются в этой версии. Android runtime-проверка импорта и визуального рендеринга ещё необходима.
