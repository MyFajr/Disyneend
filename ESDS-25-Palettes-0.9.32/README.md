# Rainbow Multicolor — 25 палитр ESDS 0.9.32

- `palettes/`: 25 JSON-файлов формата `esds-palette`, schemaVersion 4, плюс collection manifest для ZIP-импортёра.
- `theme-packs/`: 25 полных `esds-theme-pack`, schemaVersion 1; каждый содержит палитру, индивидуальный фон и стиль блоков.

## Импорт
1. Скачай ZIP этой GitHub-ветки.
2. Для массового импорта палитр используй файлы из `palettes/` через «ZIP-коллекция».
3. Для полного оформления импортируй отдельный JSON из `theme-packs/` через «Импорт дизайнерского набора».

Фон и стиль блоков имеют одинаковые light/dark значения. Все 11 ролей, включая `letter`, и 12 Callout типов заполнены. 30 семантических классов обслуживаются ESDS 0.9.32. Индивидуальные фоны столбцов Markdown-таблиц в 0.9.32 не поддерживаются. Android runtime-проверка импорта и визуального рендеринга ещё необходима.
