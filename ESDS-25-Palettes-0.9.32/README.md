# 25 полных дизайнерских наборов ESDS 0.9.33

Каждый JSON — `esds-theme-pack` schemaVersion 1 с тремя согласованными компонентами: палитрой, индивидуальным насыщенным градиентным фоном заметки и стилем информационных блоков.

В каждом наборе:
- все 11 цветовых ролей, включая отдельный цвет иностранной буквы;
- индивидуальный фон, подобранный под цвета палитры;
- одинаковые значения Light и Dark, чтобы переключение темы Obsidian не меняло вид заметки;
- стиль блоков и 12 поддерживаемых типов Callout;
- оформление семантических классов ESDS.

Импортируй каждый JSON отдельно через **«Импорт дизайнерского набора»** в ESDS 0.9.33. Импортёр добавляет три компонента в библиотеку и связывает их автоматически.

Контраст текстовых цветовых ролей рассчитан для обоих концов каждого фонового градиента; минимальное значение — 4.5:1. Это расчётная проверка, а не замена визуальному тестированию на Android.

Ограничение ESDS 0.9.33: индивидуальные фоны отдельных столбцов Markdown-таблицы пока не поддерживаются.
