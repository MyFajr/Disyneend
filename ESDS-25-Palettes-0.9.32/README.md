# Rainbow Multicolor — 25 палитр ESDS 0.9.32

- `palettes/`: 25 JSON-файлов формата `esds-palette`, schemaVersion 4, и manifest для ZIP-импортёра.
- `theme-packs/`: 25 JSON-файлов формата `esds-theme-pack`, schemaVersion 1; каждый содержит палитру, фон и стиль блоков.

## Импорт
1. Скачай ZIP этой GitHub-ветки.
2. Для массового импорта палитр используй JSON-файлы из `palettes/` в ZIP-импортёре ESDS.
3. Для полного оформления импортируй отдельный JSON из `theme-packs/` через «Импорт дизайнерского набора».

## Совместимость и ограничения
- 11 цветовых ролей, включая отдельную роль `letter`.
- 12 штатных Callout-типов, цветовые карты и рамки.
- Все 30 семантических классов обслуживаются ESDS 0.9.32.
- Для одинакового вида при переключении темы Obsidian значения light/dark фона и стиля блоков одинаковы.
- Индивидуальные фоновые цвета отдельных столбцов Markdown-таблицы в 0.9.32 не поддерживаются.
- Android-проверка реального импорта и визуального рендеринга на устройстве ещё необходима.
