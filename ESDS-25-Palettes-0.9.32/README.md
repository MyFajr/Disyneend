# 25 полных дизайнерских наборов ESDS 0.9.32

Каждый JSON — `esds-theme-pack` schemaVersion 1 с тремя связанными компонентами: палитра, яркий индивидуальный фон и стиль блоков. Импортировать по одному через «Импорт дизайнерского набора». Фон и параметры блоков имеют одинаковые light/dark значения. Все 11 цветовых ролей, включая `letter`, и 12 штатных Callout типов заполнены. Индивидуальные фоны столбцов Markdown-таблиц в 0.9.32 не поддерживаются. Android runtime-проверка ещё необходима.
