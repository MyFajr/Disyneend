# ESDS 0.9.27

- Исправлен критический дефект: все действия, использующие `window.prompt()` (не поддерживается в Obsidian/Electron), переведены на модальные диалоги ввода. Заработали: переименование палитр, переименование и создание категорий (менеджер категорий), перемещение палитр и других элементов в категорию.
- Перемещение в категорию теперь выполняется через модальный выбор «существующая/новая категория» вместо ручного ввода текста.
- Меню управления категорией («⋯» на папке) добавлено для фонов и стилей блоков — ранее было только у палитр: переименование, удаление с переносом элементов, перестановка вверх/вниз.
- Переименование фонов и стилей блоков добавлено в меню элементов каталога.
- Режим массового выделения в каталоге библиотеки: флажки на карточках, «Выбрать всё»/«Снять выбор», счётчик; массовое перемещение в категорию, массовое удаление, массовый экспорт.
- Массовый экспорт выбранных элементов в ZIP (любой тип) и в объединённый JSON (`esds-export`).
- Импорт объединённого JSON-экспорта `esds-export` с маршрутизацией элементов по типам и пропуском дубликатов.
- Расширенная сортировка для всех трёх каталогов: порядок добавления, А—Я, Я—А, сначала новые, сначала старые, по категориям; селектор сортировки добавлен в каталог библиотеки для всех типов.
- Менеджер категорий теперь синхронизирует активный выбор категории студии после переименования/удаления (раньше открытая категория «терялась»).
- ZIP-запись вынесена в общий `saveZipArchive`; экспорт палитр в ZIP сохраняет прежний формат `esds-palette-collection`.
- Новые стили интерфейса: панель массовых операций, флажки выделения, модальный ввод, меню категорий.
