# ESDS 0.9.25

- Убран переключатель Light/Dark из предпросмотра палитр: показывается один фиксированный вариант.
- Исправлено описание библиотеки, больше не обещает переключение тем палитры.
- Добавлено меню действий на карточки категорий: переименование, удаление, изменение порядка; системные категории защищены.
- Добавлены действия пользовательских палитр: переименование, перемещение, изменение порядка, редактирование, дублирование, экспорт и удаление.
- Встроенные палитры защищены от переименования и удаления.
- Сортировка по пользовательскому порядку учитывает элементы без явного order.
